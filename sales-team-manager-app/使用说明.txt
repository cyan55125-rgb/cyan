【如何打开】
  Mac 用户：双击「启动系统.command」
  Windows用户：双击「启动系统.bat」
  或者直接双击 index.html

【功能介绍】
  ✓ 新增客户：点击右上角「新增客户」按钮，可设置上级关系
  ✓ 新增销售：为客户录入产品名称和销售金额
  ✓ 树形查看：左侧展示所有客户的层级关系
  ✓ 数据汇总：点击任意客户，查看个人及团队总销售额
  ✓ 搜索功能：顶部搜索框可快速查找客户，上级支持搜索选择

【数据存储】
  所有数据保存在浏览器本地，关闭浏览器后数据不会丢失。

【分享给他人】
  将整个文件夹复制给对方，对方双击即可使用。

【兼容性】
  Chrome / Safari / Edge / Firefox 均可使用
  支持 Windows、Mac、Linux 系统
