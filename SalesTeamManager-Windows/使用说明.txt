【如何启动】
  方法一（推荐）：双击 "启动系统.bat"
  方法二（无黑窗口）：双击 "静默启动.vbs"

【系统要求】
  需要安装以下软件之一：
  ✓ Python  （下载：https://www.python.org/downloads/）
  ✓ Node.js（下载：https://nodejs.org/）

  大多数电脑已预装 Python，直接双击即可使用。
  如果提示缺少环境，安装上方软件后重新打开即可。

【功能介绍】
  ✓ 新增客户：点击右上角「新增客户」按钮，可搜索选择上级关系
  ✓ 新增销售：为客户录入产品名称和销售金额
  ✓ 树形查看：左侧展示所有客户的层级关系
  ✓ 数据汇总：点击任意客户，查看个人及团队总销售额
  ✓ 全局搜索：顶部搜索框快速查找客户
  ✓ 上级搜索：新增客户时支持输入关键词搜索上级

【数据存储】
  所有数据保存在浏览器本地，关闭浏览器不会丢失。

【分享给他人】
  将整个文件夹复制给对方，对方双击启动即可使用。

【关闭方法】
  在命令窗口中按 Ctrl+C 即可停止服务。

───────────────────────────────────────────────
  适用系统：Windows 7 / 8 / 10 / 11
  浏览器要求：Chrome / Edge / Firefox 均可
